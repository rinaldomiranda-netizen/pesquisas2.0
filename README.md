# Pesquisa 2.0

Aplicação PWA para gestão de pesquisa de campo.

## Módulos
- Dashboard
- Novo cadastro
- Setores e sessões
- Relatórios / CSV
- Pesquisadores e links individuais
- Diretoria
- Importar base CSV/Excel
- Entrevista para pesquisador

## Regra de alocação
Cada sessão admite no máximo duas pessoas, sendo uma no período da manhã e uma no período da tarde. A validação é feita pelo backend.

## Instalação
Depois que o site estiver publicado por HTTPS:
- **Android/tablet:** abrir no Chrome/Edge e usar “Instalar app” ou “Adicionar à tela inicial”.
- **iPhone/iPad:** abrir no Safari, compartilhar e escolher “Adicionar à Tela de Início”.
- **Windows:** abrir no Edge/Chrome e usar o ícone de instalação na barra de endereço ou menu do navegador.

O ícone P2 e o manifest já estão incluídos no projeto.

## Acesso
O pesquisador entra pelo link individual gerado pelo administrador. A senha inicial é `1234` e deve ser alterada conforme a rotina de segurança definida pelo sistema.
